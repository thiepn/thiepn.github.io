An interactive exam-preparation environment for Analysis II with questions, visual mathematics, practice modes, and mock-exam workflows.

The laboratory framing is deliberate: parameters, graphs, and formal results are placed in the same exercise flow so symbolic work can be connected to visual intuition. Exam-style tasks then turn that understanding back into the language and constraints of the course assessment.
