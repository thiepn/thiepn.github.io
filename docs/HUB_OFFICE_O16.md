O16 is a substantial but self-contained native improvement to the original Markdown source editor:
- Use original O9 documentSections/outlineFor authority (excluding fake headings within code fences) to insert a *following sibling section* or *nested child subsection* after a complete selected section, including its subsections. No clipping, reordering or replacement of existing source; original IDs and retained history unchanged.
- User-entered single-line heading title is validated (1–100 chars), child depth is bounded at Markdown level 6, original 200,000-character body bound enforced before mutation. Supports current source caret and exactly EOF as a valid section location; stale offsets, invalid titles or sizes fail without modifying text.
- Native buttons next to the original outline plus source keyboard productivity: Ctrl/Cmd+Shift+Enter inserts a following section using the explicit title at the current caret, Ctrl/Cmd+Alt+Up/Down moves between authentic heading offsets, and previous/next heading buttons provide accessible non-shortcut alternatives. The original textarea receives focus and title selection. No global keyboard interception, new editor or secondary state.
- Each successful insertion replaces only in-memory original source text and dispatches its existing input event, triggering the original CAS autosave/revision retention/backup/recovery. Busy/conflict/privacy/owner changes guard insertion, clear the staged section title, and disable actions. No new DB, queues, grading or cross-app authority.
- Pure tests cover Unicode, nested boundaries, sibling and child sections, excluded fenced-code headings, keyboard heading offsets, exact EOF, invalid depth/titles, stale headings, and maximum document size. Playwright tests cover actual native source creation and historical reload, keyboard shortcuts on authentic headings, mobile privacy and fail-closed depth.
