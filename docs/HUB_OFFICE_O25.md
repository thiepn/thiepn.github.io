# Hub Office O25 — Source-backed three-way citation conflict resolution

Parent O24 `5253add2270b4c9065cb70bef09352f75beeed95`. Same original draft PR #175, branch `feature/hub-office-o1-native-documents`.

The existing Office document-history and citation workbench now compare three *retained original* states: an older baseline revision, a later proposed revision, and the active saved current revision. O25 classifies genuine definition edits by original canonical footnote ID as proposed-only (safe), divergent current-versus-proposed conflicts, already-applied, or structurally blocked additions, removals, unsupported content and duplicates. It never infers citation renames, independently verifies sources, or implicitly chooses a winner. To proceed the user must choose Keep current or Use proposed for every actionable citation, with blocked cases stopping the combined preview entirely. All choices must be explicit even for changes made only in the proposed revision. The complete resulting original Markdown is shown read-only before application.

The engine reuses O21's exact definition replacement, O23's one-definition preview and O24's bounded multi-selection reconciliation; only the original Office v1 textarea and existing CAS/autosave/history own writes. Source text is preserved for unrelated current paragraphs/footnotes. All operations enforce retained baseline/proposed source identity, document owner, ID, original current revision, source text and decisions; any source, owner, save, document or privacy change clears the review. No new store, editor, index, schema, shadow history, persistent engine or external provenance claims.

Original-source tests cover truly divergent choices, proposed-only edits, already-applied, blocked missing/added/duplicate citations, fences, control limits and no-op choices. Desktop/mobile browser regressions cover conflict resolution/preview/reload, cancellation, changed source, privacy masking and cross-tab CAS. Account-before-consent and historically observed WebKit refresh remain separate release blockers. No merge, deployment, migrations, production writes, credentials, paid manually triggered CI or costs.
