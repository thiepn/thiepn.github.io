# O28 — Original citation-use impact and portable source audit

O28 remains on original draft PR #175 and branch `feature/hub-office-o1-native-documents` based on O27 head `1f4a05ea02c854545a7ef72422b8280b7339ba81`.

O27 Quality exposed a reproducible **test harness bug**, not a citation parser defect: tests/unit/office-footnotes.test.ts line 379 invoked previewOfficeDuplicateResolution inside expect instead of passing a callback to toThrow. O28 repairs the specific executable failing assertion without weakening the original expected rejection. O26 Quality was cancelled after its source/Vitest and some browser stages; independent Library and Reading remain failed on pre-consent Account IndexedDB.

O28 is read-only and distinct from O19–O27 writer/recovery features. It reuses the original Markdown-only footnote report to enumerate actual footnote use positions, line numbers and author-written passage excerpts (not rendered HTML or citation verifications). It optionally compares the current saved document with any retained Office v1 revision; a multiset of genuine full-line contexts, not absolute line numbers, distinguishes added/changed from removed/changed use passages, preserving repeated identical citations and ignoring fenced or inline-code pseudo-references. It reports original definition changes, missing/duplicate/unused source-local problems, use counts, and historical versus current site excerpts. A chosen citation can jump to any original source offset; the baseline button opens native Office retained-history preview.

The user can explicitly download a complete plain-text citation-use audit containing original IDs, saved revision metadata, original use-site line/offset, current and historical definition text, issue kinds, and changed-use passages. The report says external sources are **not verified**. Downloads use the original Office Blob download path, do not transmit data, and create no persistent writer, index, database, schema, or shadow record. The auditor stores only transient UI state and clears reports on document, revision, owner, source or privacy changes. Source-identity, original CAS and account owner checks fence all navigation/export controls. Malformed/excessive source reference identities fail closed without silent truncation. No deployment, merge, migration, credentials, production write, manually triggered paid CI or costs.

Unit regressions: actual Unicode/CRLF/fenced/inline references, repeated use contexts, line insertion versus changed use passage, changed definitions, orphaned refs, source limits, exported report content/safety metadata. Browser regressions: original citation navigation, retained comparison, explicit local file export, multiple site selection, reload, mobile privacy and multi-tab stale CAS protection.
