## Provenance and boundary

The tested SHA is the actual checkout (PR merge ref when triggered by PR). The context includes repository, run ID, attempt, checkout SHA and Git tree SHA, package-lock SHA-256, Node version, platform/architecture and Playwright version. Tracked source drift is rejected. All artifacts are downloaded from the same workflow run with attempt-specific names. Rerun all jobs, not only failed jobs, because mixing attempts is deliberately rejected. No privileged secret or private owner checkout; contents read only and checkout credentials not persisted. No publishing permission. No cache or untrusted report may substitute for release authorization.
