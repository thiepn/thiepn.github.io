## Usage

```sh
node --test tests/ci/cutover-rehearsal.test.mjs
node scripts/ci/cutover-rehearsal.mjs plan
node scripts/ci/cutover-rehearsal.mjs inspect
```

Inspect uses public GitHub API reads; an optional read-only GITHUB_TOKEN can avoid rate limits. An offline run/job evidence array may be passed as a JSON file. Inspect exits nonzero if parent checks are not all passed. The plan command always returns PROPOSED_ONLY and activation=false; the code never changes remote state. Eight native test scenarios cover evidence identity, failure handling, private skip conditions, routing, fallback and exact-main preservation. These join existing CI tooling invocations. No merge, deployment or settings changes authorized by this package.
