# O27 — Original duplicate footnote definition triage

Original draft PR #175, branch `feature/hub-office-o1-native-documents`, exact O26 parent `ea4630488426d5b50629aa0279d6a7677a78f441`.

O27 extends original O19 source diagnostics with a distinct original-citation duplicate-definition triage. The original footnote analyzer identifies authentic, outside-fence definition lines by immutable footnote ID, exact offset, line, raw text, and CRLF/CR/LF ending. The review shows multiple competing genuine definitions and explicit per-line preservation controls. Users select exactly one, inspect removed original lines and full resulting Markdown in a read-only preview, and must confirm to mutate the existing Office original textarea through its single CAS/autosave writer and bounded revision history. No citation usage, other definitions, original IDs, surrounding Markdown, or fenced pseudo-definition is rewritten.

Bounded checks refuse unsupported/oversized original source, more than 20 original candidates for one ID, invalid IDs, stale offsets, missing duplicates, unsupported/empty chosen definition text, and potentially multiline continuation indentations. Post-preview validation re-reads all original citation markers and the exact kept line; any mismatch fails closed. The review is scoped to current owner, document, revision and exact source. Changes to source, document, privacy, selection, and saved revisions clear staged data. Original multi-tab CAS remains authoritative, and the local unsaved text stays exportable on conflicts.

Unit regressions cover authentic fences, offset and Unicode source, CRLF and CR-only line endings, deletion of competing original definitions with untouched reference uses, exact kept position, selected-offset failure, source cap, too many candidates, empty content and indented continuation. Real browser regressions include review/select/preview/save/reload, cancellation, multiple groups, code fence preservation, mobile privacy and cross-tab CAS. This does not create an editor, second writer, store, index, schema or external citation authority. Account consent and WebKit token refresh remain independent release blockers. No merge, deployment, migration, production writes, credentials, manually triggered paid CI or costs.
