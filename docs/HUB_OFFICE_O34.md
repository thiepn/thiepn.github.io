## User functionality
Writers may review up to 20 authentic Markdown tables from the original document, inspect up to 40 body rows per table (2–8 columns), navigate to the original source position, edit a selected cell with exact original line spacing, append a row using actual column-specific input fields, or remove a selected original data row. Each operation shows the complete resulting Markdown in a read-only preview and requires explicit confirmation. Cancel never writes. Confirm recomputes the original table operation with matching source/revision/owner/title and dispatches through the existing single Office textarea, IndexedDB v1 autosave, revision history and CAS conflict checks.

O34 exports the actual inert Markdown renderer's table cell and divider helpers for reuse rather than adding a second table parser or renderer. Inspection uses the original fenced-source visitor, exact original source UTF-16 offsets, original CRLF/LF/CR line endings and conservative canonical pipe syntax. Unsupported, inconsistent or oversized tables fail closed. Editing preserves unrelated source, headings, citations, footnotes, links, code, paragraph content, other table rows and canonical IDs. A row requires the correct number of columns and at least one nonempty cell; deletion leaves at least one row; bounded cell text excludes Markdown table delimiters, control characters and newlines.

Ephemeral in-memory review and full preview clear on document/body/title changes, owner switching, privacy masking and relevant control changes. This introduces no second document editor, database, schema, persistent table state, hidden write path, fabricated source authority, network request or release action. Table rows are rendered with textContent only. UI control fields are visible only for the selected operation.
