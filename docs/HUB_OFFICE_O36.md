## Distinct writing and research capability
O36 lets a writer review genuine prose passages from another locally saved Office document, select up to twelve passages across fifteen-item pages and append source-attributed blockquote excerpts to the current working draft, using one full-document Markdown preview and explicit confirmation. The source document is never edited. The selection UI displays the actual original owner-scoped source document title, saved revision, line, section and original excerpt. The inserted quote includes actual local source title/line provenance, not an external citation or claim of independently verified evidence. The feature is neither a history recovery nor a same-document section operation.

Existing OfficeDeviceStore.list/read, original OfficeProseCitation paragraph scanner and Markdown render/source contracts are reused. Each source passage retains actual byte-derived original character offsets; fenced code, headings, tables and quote blocks are omitted by the canonical scanner. Source-local footnote markers and internal heading references are not transferred into another document where their IDs would be invalid. Other original source text, Unicode, authored inline Markdown and external links are retained in quoted source with LF-normalized excerpts. The existing target body remains byte-exact; only appended text is added, and 200,000-character limits are enforced. The original source reader and target writer use the existing IndexedDB v1 device database with no new indexes, schema, stores or background process.

## Owner, revision, privacy and races
The transient source selection, excerpt list, and preview are scoped to exact original owner scope, target ID/title/revision/body, source ID/title/revision/body, original source offsets and permission/dirty/busy state. Switching document, source, Account owner, privacy mode or changing current content drops the review and uncommitted preview. After loading source candidates, reviewing, creating preview and before confirming, asynchronous stages recheck epoch, store identity, current active target, privacy, and source identity. An actual same-owner device read revalidates the source revision/title/body immediately before preview and before applying. Confirmation recalculates all original selected spans, compares the full previewed result and dispatches the original textarea input event through the existing revision-checked writer/CAS. A source that changed in another tab fails closed; a target that changed in another tab is still rejected by the canonical target writer. No invented stable cross-document link, imported footnote identity, external source attribution, new store, scheduler, grader or independent sync engine.
