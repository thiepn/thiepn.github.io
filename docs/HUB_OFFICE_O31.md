O31 adds a substantial DISTINCT source-backed prose review queue rather than another citation editor, revision engine, bibliography index or grading system. It reads the current original Markdown and existing source footnote references to group genuine prose paragraphs, including wrapped lines and nested heading contexts. It deliberately excludes original headings, lists, blockquotes, tables, footnote definition lines, code fences, and inline-only code. Each real passage is labeled **no footnote marker**, **locally defined citation**, or **unresolved local reference** when a footnote is missing or duplicated. These statuses assert only local Markdown structure, never whether a citation is academically required, authentic or authoritative.

The Office UI filters all prose or each status and original heading path, shows 20 passages per page, and offers genuine original-source jumps, in-memory reviewed/unreviewed toggles and a per-session review count. Review status is intentionally ephemeral and is not confused with Office history or synced mastery. Current owner, document ID, saved revision, source text, edits, tab scope and privacy mask fence all controls; source changes, save, privacy and document changes erase reviewer state. The parser refuses more than 160 prose paragraphs or original source reference limits without silent truncation. No new data store, schema, persistent index, writer, synthetic source, production write, paid CI, deployment or merge.

Unit regressions cover wrapped original prose, Markdown structure and code exclusion, nested/repeated headings, CRLF/Unicode UTF-16 offsets, missing and duplicated local definitions, source and paragraph caps. Browser tests cover actual status/section filtering, source jump, review toggle, dense pagination, edits, reload, mobile privacy and peer CAS without creating any new writer.
